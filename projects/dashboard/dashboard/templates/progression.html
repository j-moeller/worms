TOKEN=...   # a token of your team
curl -H "Authorization: Bearer $TOKEN" {{ request.scheme }}://{{ request.get_host }}/api/v1/devbox/progression/

You need a token from your profile. {% if selected %}These commands are for {{ selected.name }}; the first one lists all your rounds and their ids.{% else %}ID stands for a round's id, which the first command lists.{% endif %}

curl -H "Authorization: Bearer $TOKEN" "{{ request.scheme }}://{{ request.get_host }}/api/v1/rounds/{{ round_id }}/logging/?limit=200&cursor=NEXT"
