Submit flags and logs

Make your worm use these commands to capture a VM or write logging information. Capturing a VM means submitting its flag (/etc/worms/flag on each VM).

curl -X POST https://scoring.worms.internal/submit \
  -H "Content-Type: application/json" \
  -d '{"vm_flag":"FLAG"}'
curl -X POST https://logging.worms.internal/submit \
  -H "Content-Type: application/json" \
  -d '{"log_data":{"event":"..."}}'
